# AskNow Platform Capabilities

Machine-readable capability slice for AskNow. Narrative platform knowledge lives
in `3.2 - AskNow.md` (`PLT-ASK-001`). This companion is what the Platform
Capability Agent indexes.

AskNow is HDFC's AI-powered conversational banking platform for product discovery,
servicing, and journey orchestration across digital channels. Like EVA, it is a
conversational experience layer without direct native-device hardware APIs.

## Supported Capabilities

- `authentication`: Supports OTP-based authentication and session re-verification via
  the platform's auth component. Host-app biometrics may be delegated when AskNow is
  embedded in mobile banking.
- `form_input`: Supports structured multi-field conversational forms with client-side
  validation.
- `document_upload`: Supports file attachment through the platform's attachment
  component (PDF, JPG, PNG).
- `api_action`: Supports synchronous and asynchronous backend API calls through the
  platform's action framework.
- `otp_verification`: Supports OTP request and verification as a first-class step type.
- `status_tracking`: Supports status updates surfaced back to the user as
  conversational messages.

## Unsupported Capabilities

- `native_camera_capture`: AskNow cannot invoke the device camera directly from the
  conversational layer.
- `geolocation_capture`: AskNow cannot read device GPS location.
- `push_notification_trigger`: AskNow cannot originate push notifications; the host
  app or a notification service must trigger them.
- `offline_mode`: AskNow requires an active network connection.

## Constraints

- `document_upload`: Uploads must use the platform's supported attachment component.
- `authentication`: Long-running journeys must resume after re-authentication if the
  session expires.
- `api_action`: Long-running backend calls must be modeled as asynchronous with a
  status-tracking step.
- `form_input`: Long forms should be split across multiple conversational steps.

## Notes

AskNow is suited to guided acquisition and servicing journeys that fit conversational
UI patterns. Hardware-dependent steps should be routed to native mobile banking.
